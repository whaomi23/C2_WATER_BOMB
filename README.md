# C2_WATER_BOMB

## Descripción

**C2_WATER_BOMB** es una aplicación móvil desarrollada con .NET MAUI que permite el control y monitoreo de un sistema de riego automatizado para jardines y huertos. La interfaz principal muestra el estado de dos zonas de riego (bomba de agua para jardín frontal y huerto trasero), permitiendo activar o desactivar cada bomba, visualizar el caudal de agua, el tiempo de riego y el estado actual de cada zona. El diseño es moderno, intuitivo y optimizado para dispositivos móviles.

## Características principales

- Control individual de dos zonas de riego.
- Visualización en tiempo real del caudal y tiempo de riego.
- Indicadores visuales del estado de cada bomba (encendida/apagada).
- Interfaz atractiva y responsiva, adaptada a dispositivos móviles.

## Tecnologías y lenguajes utilizados

- **.NET 9**
- **.NET MAUI** (Multi-platform App UI)
- **C#** (lógica de negocio y eventos)
- **XAML** (diseño de interfaz de usuario)

## Estructura del proyecto

- `MainPage.xaml`: Interfaz principal para el control de las bombas de agua.
- `MainPage.xaml.cs`: Lógica de eventos y control de estado.
- `Platforms/Android/`: Archivos específicos para la plataforma Android.
- `Components/Pages/Home.razor`: Componentes adicionales (si aplica).

## Requisitos

- Visual Studio 2022 o superior
- .NET 9 SDK
- Emulador o dispositivo físico Android/iOS para pruebas
